1. Introduction

1. 簡介

The Truncated Signed Distance Function (TSDF) is a volumetric representation where each voxel stores the signed distance to the nearest surface. It is the foundation for modern 3D reconstruction techniques like KinectFusion and 3D Gaussian Splatting mesh extraction.

截斷式符號距離函數（TSDF）是以體素（Voxel）為基礎的 3D 表示法，每個體素存儲著到最近表面的符號距離。它是現代 3D 重建技術（如 KinectFusion 和 3D 高斯潑濺法 3DGS 網格提取）的核心基礎。

2. Mathematical Formulation

2. 數學公式

The core of TSDF fusion is the weighted averaging of new depth observations into a global volume. For a voxel $\mathbf{p}$:

TSDF 融合的核心是將新的深度觀測值加權平均整合進全局體積中。對於體素 $\mathbf{p}$：

$$D_{i}(\mathbf{p}) = \frac{W_{i-1}(\mathbf{p})D_{i-1}(\mathbf{p}) + w_i(\mathbf{p})d_i(\mathbf{p})}{W_{i-1}(\mathbf{p}) + w_i(\mathbf{p})}$$
$$W_{i}(\mathbf{p}) = W_{i-1}(\mathbf{p}) + w_i(\mathbf{p})$$

Where:

  • $D_i(\mathbf{p})$: Cumulative signed distance.
  • $W_i(\mathbf{p})$: Cumulative confidence weight.
  • $d_i(\mathbf{p})$: New distance measurement.
  • $w_i(\mathbf{p})$: New measurement weight.

The value is truncated within $[-\mu, \mu]$ to focus computation near the surface.

其中：

  • $D_i(\mathbf{p})$：累積符號距離。
  • $W_i(\mathbf{p})$：累積信心權重。
  • $d_i(\mathbf{p})$：新的距離量測值。
  • $w_i(\mathbf{p})$：新量測值的權重。

數值會被截斷（Truncated）在 $[-\mu, \mu]$ 範圍內，以便將運算集中在表面附近。

4. Reconstruction Pipeline

4. 重建流程

This demo follows a simplified KinectFusion-style loop: the active camera captures one depth map, that single observation becomes a frame TSDF, the frame TSDF is fused into a global TSDF, and the latest field is converted into a mesh.

  1. Acquire Depth: The active virtual camera records the first visible surface hit along each ray. This produces one low-resolution depth map and one point-cloud observation for the current frame.
  2. Generate TSDF: The current frame point cloud updates a fresh frame-local TSDF. The colored voxel band shows which cells are affected by that one observation.
  3. TSDF Fuse: The current frame TSDF is merged into the persistent global TSDF by weighted averaging. Camera 1 initializes the global TSDF; later cameras refine it.
  4. Marching Cubes: Marching Cubes runs on the latest TSDF, meaning the initialized global TSDF for camera 1 and the fused global TSDF for later cameras.

This is still a browser-scale approximation: it uses low-resolution synthetic depth and lightweight normal handling, but the data dependency now matches the core demo loop of depth → frame TSDF → global TSDF → mesh extraction.

這個 Demo 採用簡化版的 KinectFusion 教學流程：先由目前的虛擬相機擷取單張深度圖，再把該觀測轉成單幀 TSDF，接著融合進全域 TSDF，最後把最新的數值場提取成網格。

  1. Acquire Depth：目前的虛擬相機朝物體中心發射視線，記錄每條光線第一次撞到表面的深度。這一步會得到單幀深度圖與對應的點雲觀測。
  2. Generate TSDF：把目前幀的點雲寫入一個新的單幀 TSDF。畫面中的體素帶顯示這次觀測實際影響到哪些格子。
  3. TSDF Fuse：把單幀 TSDF 以加權平均方式融合進持久的全域 TSDF。第一台相機只負責初始化全域 TSDF，之後的相機才會持續精煉它。
  4. Marching Cubes：Marching Cubes 永遠對最新的 TSDF 執行，也就是第一台相機初始化出的全域 TSDF，或後續融合後的全域 TSDF。

這仍然是瀏覽器規模的近似版：它使用低解析度的合成深度與較輕量的法向處理，但資料依賴已對齊這個 demo 的核心流程：depth → frame TSDF → global TSDF → mesh extraction。

5. How to Read Each Visualization

5. 如何閱讀每個視覺化結果

  • Camera pyramids + scan rays: indicate where observations come from and which directions are sampled.
  • Red points: discrete surface samples reconstructed from depth images, including synthetic measurement noise.
  • Yellow voxels: cells that fall inside the truncation neighborhood of the points and therefore participate in fusion.
  • Blue mesh: the final zero-isosurface extracted from the fused field.
  • 相機金字塔與掃描射線：表示觀測是從哪裡來，以及目前取樣的方向。
  • 紅色點雲：由深度圖回投影得到的離散表面樣本，其中包含刻意加入的雜訊與離群點。
  • 黃色體素：落在點雲截斷鄰域內、因此會參與融合計算的格子。
  • 藍色網格：從融合後數值場提取出的最終零等值面。

6. Why Noise and Outliers Matter

6. 為什麼雜訊與離群點很重要

Real sensors and learned renderers are imperfect: depths jitter, normals are approximate, and some samples are simply wrong. TSDF fusion is useful because it converts many noisy local observations into a smoother global field. If enough observations agree, the zero crossing stays stable even when individual samples are messy.

真實感測器與學習式渲染器都不完美：深度會抖動、法向量只是近似、有些樣本甚至完全錯誤。TSDF 融合的價值就在於，它能把大量局部且帶噪的觀測整合成更平滑的全域數值場。只要足夠多的觀測彼此一致，零交叉面就能保持穩定，不會被單一錯誤樣本主導。

7. GUI Parameters Reference

7. GUI 參數說明

Grid Resolution

The N in the shared N×N×N voxel grid used by voxelization, TSDF fusion, and Marching Cubes. All three steps must use the same grid, so this is a top-level setting.

Since the world space spans $[-2, 2]^3$ (extent = 2.0), voxel size is: $$\text{voxelSize} = \frac{2 \times \text{extent}}{N} = \frac{4}{N}$$The GUI shows the current voxel size as a read-only field (↳ Voxel Size) directly below the slider.

  • Higher N: finer surface detail, but memory and compute scale as N³. At N=64, voxelSize = 4/64 = 0.0625; at N=32, voxelSize = 0.125.
  • Lower N: faster, but the extracted mesh looks blocky because a sphere of radius 1 only spans $2/\text{voxelSize}$ voxels across its diameter.

Gaussian Splat (Step 1)

  • Surface Type: The underlying geometry (sphere or torus) that gaussian centers are sampled from. Changing this regenerates the whole splat scene.
  • Gaussian Count: Number of gaussian instances. More gaussians = denser point clouds and more stable frame/global TSDF updates.
  • Splat Noise: Controls the probability and magnitude of 3DGS-style artifacts.
    • 0.0: All gaussians sit exactly on the ideal surface with no jitter — a perfect clean scene.
    • 1.0: Full artifact mix: floaters (8%, drift off-surface), needles (10%, elongated at edges), oversized blobs (7%), plus position jitter on normal gaussians.
    • The generated positions are passed directly to the worker as the Step 2 point cloud, so the splat distribution is faithfully reflected in reconstruction.

TSDF Volume

  • Truncation μ in voxels (Steps 2–3): The half-width of the truncation band, expressed as a number of voxels. The actual world-space distance is $\mu = \mu_\text{voxels} \times \text{voxelSize}$, so it automatically scales with resolution.
    • In Step 2, it defines the frame-TSDF truncation neighborhood around each observation.
    • In Step 3, the same truncation band controls how much of that frame TSDF contributes during fusion.
    • Larger μ → wider band, smoother field, but blurrier surfaces and more outlier influence. KinectFusion recommends 3–5 voxels.
    • Smaller μ → sharper surfaces, but gaps may appear where surface coverage is thin.
  • Observation Weight (Steps 2–3): The per-point weight $w_i$ in the weighted average $$D_i = \frac{W_{i-1}D_{i-1} + w_i d_i}{W_{i-1} + w_i}$$ Higher values make each new observation dominate the running average more. In this demo every gaussian point is fused exactly once, so changing this parameter uniformly scales all contributions — the relative effect on the final SDF is minimal. In a real incremental system (e.g. KinectFusion), a higher weight would let new depth frames correct the field faster, but would also amplify the influence of outlier points.
  • Max TSDF Weight (Step 3): Cap on the cumulative weight $W_i$, i.e. W_i = min(W_{i-1} + w_i, maxWeight). This prevents early observations from permanently dominating the average as more frames arrive.
    • Lower cap: the field stays responsive to new data — useful in dynamic scenes where surfaces move.
    • Higher cap: the field converges more confidently as observations accumulate, but reacts slowly to corrections.
    • Note: In this demo the point cloud is fused in a single pass, so each voxel is only observed once. The weight cap is never reached and this parameter has no visible effect. It becomes meaningful when the same scene is scanned multiple times (incremental fusion).

Grid Resolution

三個步驟共用的 N×N×N 體素格子的邊長 N。體素化、TSDF 融合、Marching Cubes 三者必須使用同一個格子，因此這是頂層共享參數。

場景世界空間範圍為 $[-2, 2]^3$（extent = 2.0），因此 voxel 大小為：$$\text{voxelSize} = \frac{2 \times \text{extent}}{N} = \frac{4}{N}$$控制面板在 Resolution 滑桿正下方有 ↳ Voxel Size 唯讀欄位，即時顯示目前的格子大小。

  • N 越大：表面細節越精細，但記憶體與計算量以 N³ 成長。N=64 時 voxelSize = 0.0625；N=32 時 voxelSize = 0.125。
  • N 越小：速度快，但提取出的網格會呈現方塊感，因為半徑 1 的球只橫跨 $2/\text{voxelSize}$ 個格子。

Gaussian Splat （Step 1）

  • Surface Type：Gaussian 中心點採樣的基底幾何（球體或環面）。更換後會重新生成整個 splat 場景。
  • Gaussian Count：Gaussian 實例數量。越多代表點雲越密集，單幀與全域 TSDF 也會更穩定。
  • Splat Noise：控制 3DGS 風格 artifact 的出現機率與偏移幅度。
    • 0.0：所有 gaussian 精確落在理想表面上，無任何偏移，代表完美的重建場景。
    • 1.0：完整 artifact 配置：floater（8%，漂浮在表面外）、needle（10%，邊緣處的細長型）、oversized blob（7%，覆蓋均勻區域的大型 gaussian），加上一般 gaussian 的位置抖動。
    • 生成的位置會直接傳給 worker 作為 Step 2 的點雲來源，因此 splat 分布會忠實反映到重建結果中。

TSDF Volume

  • Truncation μ（voxel 數，Steps 2–3）：截斷帶的半寬度，以格子數為單位。實際世界空間距離為 $\mu = \mu_\text{voxels} \times \text{voxelSize}$，因此會自動隨 resolution 縮放。
    • 在 Step 2 中，它決定單幀 TSDF 在每個觀測點周圍的截斷鄰域。
    • 在 Step 3 中，同一個截斷帶會決定這份單幀 TSDF 能如何影響全域 TSDF。
    • μ 越大 → 截斷帶越寬，數值場越平滑，但表面較模糊、離群點影響範圍也更大。KinectFusion 建議使用 3–5 格。
    • μ 越小 → 表面越銳利，但若點雲覆蓋率不足，可能出現破洞。
  • Observation Weight（Steps 2–3）：加權平均公式 $$D_i = \frac{W_{i-1}D_{i-1} + w_i d_i}{W_{i-1} + w_i}$$ 中每個點的單次觀測權重 $w_i$。數值越高，新觀測對目前均值的主導力越強。在本 demo 中每個 gaussian 點只融合一次，調整此參數等比縮放所有點的貢獻，對最終 SDF 的相對影響有限。在真實的增量式系統（如 KinectFusion）中，較高的權重讓新深度幀能更快修正數值場，但也會放大離群點的影響。
  • Max TSDF Weight（Step 3）：累積權重 $W_i$ 的上限，即 W_i = min(W_{i-1} + w_i, maxWeight)，防止早期觀測隨著幀數增加而永遠主導均值。
    • 上限較低：數值場持續對新資料保持響應——適合動態場景或表面有移動的情況。
    • 上限較高：觀測累積後收斂更穩定，但對後續修正的反應較慢。
    • 注意：本 demo 的點雲是單次全量融合，每個體素最多只被觀測一次，權重上限永遠不會被觸及，因此此參數在 demo 中沒有可見效果。在同一場景被重複掃描（增量式融合）時才會發揮作用。
